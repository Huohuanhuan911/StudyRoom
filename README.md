# StudyRoom 自习室预约系统
> 课程小组实训项目
本人主要负责后端接口开发、数据库对接、与前端完成前后端联调工作。

## 📖 项目简介
自习室座位预约管理系统，面向在校学生实现账号登录认证、自习室与座位信息浏览、座位预约提交、个人预约记录查询管理等业务。
项目采用前后端分离架构开发；前端负责页面渲染与用户交互，后端负责业务逻辑处理、权限校验以及持久化数据存储。

## 🛠️ 技术栈
**后端**
- SpringBoot 3.2.5 (Java21)
- Spring Data JPA + Hibernate（ORM持久层）
- SQLite 嵌入式数据库
- Spring Security + JWT 实现登录鉴权
- SpringDoc‑OpenAPI 自动生成接口文档
- Lombok简化实体类代码

**前端**
- Vue3 + Vite
- Vue‑Router4
- Axios 用于http请求

## ✨ 主要负责模块
1. **数据库层设计与对接**：完成业务实体设计，基于JPA‑Hibernate完成实体与SQLite数据表映射，实现数据持久存取。
2. **后端REST接口开发**：编写用户登录注册、自习室座位查询、预约提交、预约记录查询等业务接口；统一封装接口返回JSON结果。
3. **JWT权限对接**：配合SpringSecurity实现token鉴权；校验用户登录状态，未登录用户拦截预约相关请求。
4. **前后端联调**：和前端同学协商接口入参、返回字段；使用OpenAPI文档对齐接口定义；调试Axios请求，处理跨域与参数传输问题，打通前后端业务数据流。
5. **业务逻辑校验**：增加重复预约、预约时间冲突校验逻辑，对非法请求返回业务错误提示，提升接口健壮性。

## 🚀 本地运行步骤
### 后端启动
1. Java版本需要21；
2. Maven加载全部依赖；
3. 直接运行SpringBoot启动类；
> 本项目使用SQLite嵌入式数据库，无需额外安装数据库服务，程序运行会自动生成db数据库文件；访问 `/swagger-ui.html` 可以查看OpenAPI接口文档。

### 前端启动
```bash
# 安装依赖
npm install
# 开发运行
npm run dev
# 打包构建
npm run build
